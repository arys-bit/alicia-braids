# Alicia Braids — Landing Page

Landing page responsiva criada para Alicia Braids, com foco em agendamentos pelo WhatsApp.

## Conteúdo

- Hero com posicionamento de autoestima e identidade
- Serviços e valores a partir de
- Galeria com trabalhos reais
- Apresentação da profissional
- Cursos com certificado e consulta de valores atuais
- Informações de atendimento, pagamento e reserva
- Links diretos para WhatsApp e Instagram

## Abrir do jeito mais simples

Dê dois cliques no arquivo `index.html`. A página abrirá diretamente no navegador, sem terminal.

## Rodar com servidor de desenvolvimento — opcional

```bash
npm install
npm run dev
```

## Gerar a versão de produção

```bash
npm run build
```

A versão pronta para publicação será gerada em `dist/client`. Para GitHub Pages, também é possível publicar diretamente os arquivos da pasta principal.

## Observações

- Os valores de serviços são apresentados como “a partir de”, conforme o catálogo fornecido.
- Os valores antigos dos cursos não foram publicados. O botão consulta as próximas turmas e o preço atual pelo WhatsApp.
- O endereço público mostra apenas Jd. São Guilherme — Sorocaba/SP.
- Todas as imagens possuem versão com 3.840 pixels no lado maior. As marcas transparentes utilizadas na página estão em WebP 4K para preservar qualidade e reduzir o peso de carregamento.
